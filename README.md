# Soda Truck

A one-button game about making orange soda.

- Press **Space** when an ingredient enters the green zone to add it.
- Let unwanted ingredients pass.
- Add orange and soda to complete a drink, in either order.
- Picking cherry or a duplicate ingredient counts as a mistake. Two mistakes end the game.
- Press **Space** after a drink is finished or time runs out to start the next one.

Open the project in Godot and press **F5** to play.
