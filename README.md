# Soda Truck

A one-button game about making fruit soda.

- Press **Space** when an ingredient enters the green zone to add it.
- Let unwanted ingredients pass.
- Check the customer's thought bubble for a random orange, blueberry, strawberry, or grape soda order.
- Add the matching fruit and soda in either order. Every pick appears to the right of the cup; fruit is shown as syrup.
- Ingredients move faster after each drink, up to a maximum speed.
- Picking cherry, the wrong fruit, or a duplicate ingredient counts as a mistake. Two mistakes during one drink end the game.
- Press **Space** after a drink is finished or time runs out to start the next one.

Open the project in Godot and press **F5** to play.
